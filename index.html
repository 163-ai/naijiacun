语音设置

不填也能听。站点自带的转发服务会在服务端用自己的额度帮你合成，每人每天有上限。 填上自己的 Key 就没有上限了 —— Key 只保存在你自己的浏览器里，本站不上传、不记录。

音色列表来自你当前的浏览器。Edge 一般自带「Xiaoxiao / Yunxi」等自然音， Chrome 可能只有一两个机械音 —— 想听真音色请用 Breeze Key。

🔒 管理 · 审核 / 删除

这个面板只给拥有 163-ai/naijiacun 写权限的协作者用。删除会直接改仓库里的 js/data.js 并提交到 main，GitHub Pages 约 1~2 分钟后重新发布。 没有写权限的账号，GitHub 会直接拒绝提交 —— 所以光打开这个面板删不掉任何东西。

两种 Token 任选其一：经典 Token（github.com/settings/tokens/new，勾 repo 权限） —— 仓库在别人个人账号名下时只能用这种； fine-grained Token（只授权本仓库 Contents: Read and write） —— 仅当仓库在你自己名下或在组织里时可用。 Token 只存在你自己的浏览器里（不勾选「记住」则关闭页面即失效），建议都设置有效期。
