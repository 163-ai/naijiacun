## 一、结论先行

数值体系**半成体系**：有 4 个集中配置表（招式表 MOVES、怪物分布 ZONES、作物表 CROPS、瓦片表 TI），但成长公式与战斗系数原本散落在函数体内，无统一配置入口。

**最严重问题**：`atk`（攻击力）是死字段——被定义、存档、升级加点、传入战斗模块，但伤害公式从不读取它，属于"虚假成长"。

本次修复后：**战斗平衡数值完全不变**（逐等级、逐系数验证差值为 0），但 atk 成为真实可调属性；经济、捕捉、后期成长三处平衡问题已修正；战斗/成长系数已集中为可配置块。

## 三、修复清单

### P0 · 致命问题

1. **ATK 死字段修复**（`js/kof.js`）
   - 原公式：`dmg = mv.dmg * (1 + (lv-3)*.07)`，只认等级。
   - 新公式：`dmg = mv.dmg * (1 + (a.atk - ATK_BASE) * DMG_PER_ATK)`，其中 `ATK_BASE=28`、`DMG_PER_ATK=.07/3`。
   - 等价性：当 `atk = 28+(lv-3)*3` 时，新旧公式**逐等级完全等价**（Lv2\~30 最大差 0），现有平衡不变。
   - 敌人 atk 由废弃的 `20+lv*4` 改为同曲线 `28+(lv-3)*3`。
   - 老存档 atk 天然落在新曲线上，**无需数据迁移**。
   - 收益：以后装备、道具、天赋改 atk 都会真实反映到伤害。
2. **升级提示漏报**：补上"攻击 +3"。

### P1 · 平衡问题

1. **后期失衡**（`js/game2d.js`）：敌人等级上限 12 → 30。原封顶会让高等级玩家 3 秒秒杀满级怪，挑战归零。
2. **捕捉偏易**（`js/kof.js`）：概率公式 `(1-r)*.82+.22 (max .95)` → `(1-r)*.70+.16 (max .88)`。
   - 30% 血：79% → 65%；10% 血：95% → 79%。保留"残血更好抓"，不再近乎必中。
3. **作物经济梯度**（`js/farm.js`）：售价 萝卜 44→48 / 玉米 78→76 / 甜瓜 132→118，甜瓜成本 55→60。
   - 金/天/格：8.0 / 10.8 / 15.4 → **9.3 / 10.3 / 11.6**，温和递增。
   - 缓解甜瓜严格支配低阶作物的问题；萝卜保留"3 天回笼资金、门槛低"的定位。

### 明显 Bug

1. 删除 `js/game2d.js` 中 `state.balls = state.balls` 的无意义自赋值。

### P2 · 工程重构（本轮新增）

1. **抽离战斗配置块**（`js/kof.js`）：新增 `BALANCE` 对象，集中格挡减伤/硬直/击退、气槽上限与回气、连击窗口、命中顿帧、AI 决策参数、捕捉参数。所有抽离值与原值逐项校验一致。
2. **抽离成长配置块**（`js/game2d.js`）：新增 `GROWTH` 对象，集中经验曲线、每级 HP/ATK 成长、敌人等级上限与 HP 公式、遭遇步长与概率、战斗经验奖励、战败恢复比例。
3. **消除命名冲突**（`js/game2d.js`）：画面曝光字段 `exp` → `exposure`（STYLES 表、STYLE\_STATE、setLight），与经验值 `state.exp` 彻底区分，消除误读风险。
4. **缓存版本**：`kof.js?v=57→58`、`game2d.js?v=87→88`，避免线上缓存导致模块导出不一致。
