一、结论先行

数值体系半成体系：有 4 个集中配置表（招式表 MOVES、怪物分布 ZONES、作物表 CROPS、瓦片表 TI），但成长公式与战斗系数原本散落在函数体内，无统一配置入口。

最严重问题：atk（攻击力）是死字段——被定义、存档、升级加点、传入战斗模块，但伤害公式从不读取它，属于"虚假成长"。

本次修复后：战斗平衡数值完全不变（逐等级、逐系数验证差值为 0），但 atk 成为真实可调属性；经济、捕捉、后期成长三处平衡问题已修正；战斗/成长系数已集中为可配置块。

三、修复清单

P0 · 致命问题

  • ATK 死字段修复（js/kof.js）
  • 原公式：dmg = mv.dmg * (1 + (lv-3)*.07)，只认等级。
  • 新公式：dmg = mv.dmg * (1 + (a.atk - ATK_BASE) * DMG_PER_ATK)，其中 ATK_BASE=28、DMG_PER_ATK=.07/3。
  • 等价性：当 atk = 28+(lv-3)*3 时，新旧公式逐等级完全等价（Lv2\~30 最大差 0），现有平衡不变。
  • 敌人 atk 由废弃的 20+lv*4 改为同曲线 28+(lv-3)*3。
  • 老存档 atk 天然落在新曲线上，无需数据迁移。
  • 收益：以后装备、道具、天赋改 atk 都会真实反映到伤害。
  • 升级提示漏报：补上"攻击 +3"。

P1 · 平衡问题

  • 后期失衡（js/game2d.js）：敌人等级上限 12 → 30。原封顶会让高等级玩家 3 秒秒杀满级怪，挑战归零。
  • 捕捉偏易（js/kof.js）：概率公式 (1-r)*.82+.22 (max .95) → (1-r)*.70+.16 (max .88)。
  • 30% 血：79% → 65%；10% 血：95% → 79%。保留"残血更好抓"，不再近乎必中。
  • 作物经济梯度（js/farm.js）：售价 萝卜 44→48 / 玉米 78→76 / 甜瓜 132→118，甜瓜成本 55→60。
  • 金/天/格：8.0 / 10.8 / 15.4 → 9.3 / 10.3 / 11.6，温和递增。
  • 缓解甜瓜严格支配低阶作物的问题；萝卜保留"3 天回笼资金、门槛低"的定位。

明显 Bug

  • 删除 js/game2d.js 中 state.balls = state.balls 的无意义自赋值。

P2 · 工程重构（本轮新增）

  • 抽离战斗配置块（js/kof.js）：新增 BALANCE 对象，集中格挡减伤/硬直/击退、气槽上限与回气、连击窗口、命中顿帧、AI 决策参数、捕捉参数。所有抽离值与原值逐项校验一致。
  • 抽离成长配置块（js/game2d.js）：新增 GROWTH 对象，集中经验曲线、每级 HP/ATK 成长、敌人等级上限与 HP 公式、遭遇步长与概率、战斗经验奖励、战败恢复比例。
  • 消除命名冲突（js/game2d.js）：画面曝光字段 exp → exposure（STYLES 表、STYLE\_STATE、setLight），与经验值 state.exp 彻底区分，消除误读风险。
  • 缓存版本：kof.js?v=57→58、game2d.js?v=87→88，避免线上缓存导致模块导出不一致。

四·补、第二轮补充复查（存档健壮性 / 刷钱漏洞 / 每日任务）

第一轮聚焦战斗与成长数值。第二轮对存档、经济闭环、每日任务边界做补充复查，又发现 10 个问题。本轮修复其中 8 项（全部高危 + 中危 + 2 项低危），2 项低危记录为待办。

高危（已修）

  • 竹笋刷新页面无限刷钱（js/game2d.js）：shootQuest.day/got 原本完全不入档，刷新页面后 day 复位、4 根笋重新露出，每根 +8 金可无限重复，外卖任务也重复计数。
  • 修复：shootQuest.day 与每根 got 位写入存档、读档恢复；refreshShoots() 改为"跨天才有条件清空 got、可见性按当天种子确定性重算并保持 got"，读档后不会重刷。
  • "重新开始"按钮实际在读档（js/game2d.js:6501）：原写法 startGame(!btnContinue.dataset.has)，有存档时 has="1" → 取反为 false → 走读档，玩家无法开新档。
  • 修复：btnStart 恒传 startGame(true)；"继续"按钮独立走 startGame(false)。

中危（已修）

  • 钓鱼满竿后 900ms 刷钱（js/game2d.js）：到 8 竿至 closeFishing 之间有窗口可连续收竿，每次 +12 金且把 fishRods 写成 \>8。
  • 修复：reelFish() 开头硬拦 if (fishing.rods >= FISH_RODS) { closeFishing(); return; }；closeFishing() 把 fishRods 归一到上限。
  • Farm 存档无类型校验（js/farm.js）：坏档会把 NaN/负数带进经济循环，或让整档读取失败。
  • 修复：新增 _finite/_cropCounts，所有数值字段做有限性校验 + clamp；种子/背包按 CROPS key 白名单重建；地块坐标越界丢弃、未知作物 key 当空地。
  • 存档缺版本号 + 拜访记录不入档（js/game2d.js）：state.visitOn 刷新即清，"每天首次聊天"可重复领；嵌套结构无迁移钩子。
  • 修复：visitOn 入档并在读档/新档两处恢复与重置。（内部版本号字段本轮未加，见待办。）
  • 敌人 atk 基数写死 3 处（js/game2d.js）：玩家初始、读档兜底、敌人 atk 各自硬编码 28。
  • 修复：新增共享常量 ATK_BASE=28，三处统一引用，与 kof.js 标定同源。

低危（已修 2 项 / 待办 2 项）

  • 赏金领取未落盘（已修，js/game2d.js）：claimBounty() 补 save()，异常退出不丢已领状态。
  • 存档失败静默吞掉（已修，js/game2d.js）：save() 的 catch 里加一次性节流提示。
  • 五子棋结算定时器未在 close 清理（待办，无害残留定时器，gomoku.js:264）。
  • 遭遇区世界坐标与高草视觉椭圆未对齐（待办，体验一致性，非数值问题）。
