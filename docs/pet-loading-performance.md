# 桌宠加载优化（2026-11-08）

这次保持模型、图片、声音与动作内容不变，调整请求顺序与加载依赖。

- 平面 PetRenderer 不再静态导入 Three.js、GLTFLoader 与骨骼模块；切到3D才加载，库、解码器与模型并行请求。
- `pet.html?pet=1` 直接请出悬浮角色，不先等小院渲染器；头部预加载轻量模块，角色栏图片使用低请求优先级。
- 同源角色图保持默认图片请求模式，避免与原页面图片因 CORS 设置不同而重复请求；跨源扩展资源仍使用匿名 CORS。
- 展台 GLB 预加载使用匿名 CORS，与后续 fetch 匹配。冷浏览器证实首个奶龙模型从两次下载变一次；importmap 位于 modulepreload 之前。
- 后台暖缓存每次完整下载一个再继续；弱网或省流量不预取，隐藏、离开、主动选择角色时中止并让路。

第一回使用完整3D仍需要下载所选模型。更新模型时应同步资源URL/版本及展台头部预加载地址；不要让图片/模型的 preload 与实际请求使用不同凭据模式。

本地与公网测量、平面零3D请求、透明命中/生命周期、三款模型与原动作、预加载单次下载和后台让路测试记录在项目父目录 `speed-open-20261108/`。公网时间是同一电脑的一组样本，不代表所有访问者。
