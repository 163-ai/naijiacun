# 浏览器村民桌宠实施计划

**已确认：** 用户取消 Windows 压缩包方案，接受一次 Chrome/Edge 扩展安装。所有十位村民均可跨普通网页悬浮；九位使用真实 3D 模型，小草按用户要求抠出主体作为透明 2D 角色。

**交互：** 网页“变桌宠”将当前村民与平面/3D选择传给扩展。扩展保存角色、模式、活动开关、大小和归一化位置，导航后恢复；可拖动、选择村民、暂停和收回。空白处不挡住网页操作。小草保留人物和“太棒了”牌子。

**实现：** 共用 Three.js 宠物渲染器及角色动作模块。六位双足角色用真实骨骼权重与交替腿步态；袋鼠蹦跳、奶蛋滚动/弹跳、卡皮巴拉保留碗并局部活动。扩展采用 Manifest V3、本地打包代码和模型、隔离页面样式；后台页面停止渲染，按需加载单角色。代码参考 AIRI 的真实3D生命周期和 VPet 的行为状态，不复制其角色素材。

- [x] 共用渲染/动作模块：九款模型独立审阅关键动作帧，确认四肢交替和造型，支持切回平面、销毁和透明命中。
- [x] MV3 扩展：角色选择、状态持久化、跨站恢复、网页按钮桥接、无框悬浮与拖动；复制所需本地资源形成可加载目录。
- [x] 网页桌宠：替换小窗入口、取消旧 Windows 下载引导，平面/3D真正切换，保留现有聊天和语音。
- [x] 小草抠图：移除背景，保留脸、眼镜、围巾、衣服和牌子文字，作为所有页面及扩展共用的透明图。生成式抠图并非逐像素原样，记录见素材说明。
- [x] 验证：十位选择、九位真实3D与适合各自造型的活动、跨两个网站/刷新、透明点击穿透、后台可见性分支、严格CSP、手机网页和其他页面回归。

## 验证记录

- 五个页面 × 1280/768/390/360 四种宽度：无横向溢出、JS异常或HTTP错误；原有搜索、筛选、投票、详情、盲盒、提名和设置入口通过。
- 桌宠初始平面不请求GLB；全部九位真3D可显示并行进，小草保持透明2D，切回有模型的角色可恢复3D。原聊天交互和十位头像回归通过。
- 渲染器4,830个平面alpha样本及3D命中采样无误；快速切换最后请求生效、销毁中加载、同模式复用通过。九款54个动作/视角帧已人工检查。
- 独立Chromium临时profile测试：严格 `script-src 'self'` 与 TrustedTypes 下九款真3D，腿间空隙/透明边缘点击穿透、不透明身体拖动、跨127.0.0.1/localhost导航与刷新、停止、菜单、跑动与暂停均通过；网页两个真实入口与扩展联动另行验收通过。
- 真实延迟加载A→B→A快速切换回归通过；网页切角色下载失败时回退平面并可重试。独立iframe测试确认从顶层身体开始拖动可跨入iframe并完整释放，不会操作下面的嵌入内容；身体初始就在iframe区域时无法命中，安装说明如实记录此限制及工具栏操作入口。
- Headless Chromium切标签并不触发真实 `document.hidden`；可见性分支通过VM测试，隐藏本地预览350ms内WebGL渲染调用为0，不将此表述为已验证所有原生窗口最小化行为。
- 55个已有模型、图片、音频和旧包哈希未变；当前招手奶龙模型SHA256仍为 `4263ac1b14080db792ae4bf7f6278915e1333c8965e06c1450bb14a14c6aa448`。
- 测试报告与截图保存在项目父目录的 `browser-pets-20261108/`，不将临时浏览器profile或构建输出提交到仓库。

扩展运行于普通 HTTP/HTTPS 网页；浏览器内部设置页等受限页面无法注入，切到浏览器之外的应用不会显示。首次需要一次扩展安装；当前未上架商店，开发版先提供本机可加载目录，不将网页按钮表述为能够静默安装扩展。实际用户浏览器安装在完成构建和测试后单独操作。
