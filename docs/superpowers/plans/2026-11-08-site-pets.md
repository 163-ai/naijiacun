# 奶家村全站悬浮桌宠实施计划

**目标：** 按用户已确认的方案，免安装在奶家村七个访客页面内使用同一只桌宠。用户随后明确取消本次跨网页扩展和商店上架工作；不修改已有扩展功能，不新增安装流程。

**架构：** 轻量站内启动脚本保存独立的本地状态，首次开启后才导入共用 PetRenderer。新悬浮视图管理一只角色、拖动、活动与菜单。现有小院/3D展台入口调用同一站内API，原有图鉴、聊天、盲盒、小游戏逻辑保持。

**范围与接口：**
- `js/site-pet.js`：经典脚本；`window.NaijiacunSitePet.start({id,mode,size})`、`stop()`、`getState()`；状态事件 `naijiacun-site-pet-state`，仅使用 `naijiacun_site_pet_v1` 本地存储。
- `js/site-pet-view.js` 与 `css/site-pet.css`：透明悬浮角色、菜单、真实3D活动；仅渲染当前角色、隐藏页面停止渲染，销毁时释放。
- 七页为 index、gallery、chat、pet、pet3d、game、extension。按需补齐已有数据、模型目录和Three导入映射；禁用时不导入渲染器、不请求GLB。
- pet页“变桌宠”立即站内悬浮；收回恢复小院。展台保留旋转观察功能；新站内桌宠只显示一只。小草透明2D，其余九位可切3D。
- 用户追加：所有站内悬浮界面轻点身体播放既有4700ms捧腹大笑；拖动不误触。共用展台动作曲线，结束恢复原活动；小草使用2D笑动。沿用现有笑声文件与声音开关，不调用外部语音服务。

- [x] 浏览器行为验证：首次点击可见、跨七页保留角色/模式/大小/位置、图鉴默认无GLB、关闭后导航不恢复。
- [x] 实现启动与悬浮视图，验证十角色、九真3D、快速切换、透明点击穿透、拖动、边界与菜单。
- [x] 更新入口和站内说明，移除当前页面的安装引导；小游戏菜单按键不触发游戏。
- [x] 五页既有回归、七页悬浮测试、390/360手机布局与生命周期验证、独立代码审查通过；最后普通提交同步并保留协作者新提交。
