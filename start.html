点开工坊没反应？

说明本机服务没在跑。在 naijiacun-model-forge 目录执行 npm start 起一次，或者 npm run autostart 让它常驻开机自启，再回来点。

工坊设了访问口令。用带 ?k= 的本页链接打开，口令会自动带给工坊；否则就进工坊后手动输一次。

状态灯只作参考：浏览器隐私策略偶尔会拦住本页对 127.0.0.1 的探测，显示“没连上”不代表真没起，直接点卡片最准。
