# 奶家村 · 跨网页桌宠

一次加载扩展后，十位村民可跟随普通 HTTP/HTTPS 网页。九位使用随包附带的真实 3D 模型；小草使用保留「太棒了」牌子的透明平面图。扩展不会发起 AI 聊天或收集网页内容。

## 本机安装（Chrome / Edge）

当前开发版没有上架商店，也没有商店安装链接。已构建的目录位于 `browser-extension/dist`，直接加载这个目录即可，不需要压缩包或另外安装运行环境。

1. 打开 Chrome 的 `chrome://extensions`，或 Edge 的 `edge://extensions`。
2. 打开「开发者模式」，选择「加载已解压的扩展程序」。
3. 选中本项目的 **`browser-extension/dist` 文件夹**。不要选仓库根目录或 `browser-extension` 源码目录。
4. 在扩展菜单中打开「奶家村 · 跨网页桌宠」，选一位村民，点「请到网页上」。安装前已经打开的普通网页需要刷新一次。

可在工具栏固定扩展图标。网页上的「变桌宠」按钮会将当前村民与平面/3D选择交给已安装的扩展；按钮不会静默安装扩展。

## 使用

- 拖动身体安放，靠近浏览器边缘时会停在可见区域。透明边缘、四肢之间的空隙都可直接点击后面的网页。
- 右键身体打开「村民小口袋」，或点扩展图标：切换十位村民、平面/真实3D、大小和活动方式。
- 取消「自由活动」暂停当前位置和动作；「收回」关闭所有普通网页上的村民。再次请出会恢复所选角色、大小和位置。
- 自由散步会在休息、走路、跑步之间轮换；到屏幕边缘自动转身。后台标签页会销毁渲染器，返回时按保存状态恢复。
- 小草的3D按钮不可用，始终显示透明平面；其他九位可切换真实模型。

浏览器内部设置页、扩展商店、新标签页和受限页面不能注入；切到浏览器之外的应用不会显示。默认只在网站顶层页面显示一个村民，不在每个 iframe 中重复显示。无痕窗口是否启用由浏览器扩展设置决定。

嵌入视频、跨源 iframe 等区域可能无法从身体开始拖动；从普通网页区域开始的拖动可连续跨过 iframe。遇到无法点到身体时，可从工具栏扩展图标切换或收回村民。

## 开发构建与校验

在仓库根目录执行：

```powershell
node browser-extension/build.mjs
node --test browser-extension/tests/*.test.mjs
```

构建过程才使用 Node；构建好的 `dist` 使用时只需要 Chrome/Edge。构建会先校验源文件，再替换自身 `dist`。输出仅复制：两个共用桌宠模块、必要的 Three.js/meshopt 文件和许可证、九个当前模型、十张桌宠图，以及扩展本身的脚本和界面。不会把仓库、音频、聊天逻辑或全部模型重复打进包；Three.js 源文件不会被修改，只在输出中的 GLTFLoader/BufferGeometryUtils 修正裸模块导入。

开发时重建后，在扩展管理页点「重新加载」，再刷新要测试的网页。`dist` 已忽略 Git；无需将约58 MiB的输出提交进仓库。

### 手工冒烟检查

在项目已有本地静态服务下打开 `http://127.0.0.1:8012/naijiacun/browser-extension/smoke.html`。本页有严格 CSP 与点击网格，测试按钮通过与官网相同的桥接协议调用扩展。

1. 未请出时确认网页正常。点「检查连接」，收到扩展版本与状态。
2. 依次选择十位村民。九位切到3D确认是立体模型；小草切到3D请求后返回状态必须是2D。
3. 点「收回」后打开另一个普通网站，通过扩展弹窗请出，刷新/跳转后角色、模式、大小和归一化位置保持。
4. 将宠物移到点击网格上，点透明边缘和腿部空隙，网格计数应增加；点身体拖动时网格不应触发。
5. 右键身体选择跑步，确认行进与步态同时发生、边缘转身；取消活动后位置与动作暂停；恢复活动继续。
6. 切到另一个标签页，原页面没有活动渲染器；回来恢复。分别检查后台创建的新标签页没有提前请求模型。
7. 普通第三方网页发出相同 `START`/`STOP` 消息不得控制扩展。只有官网 `/naijiacun/` 与精确本地预览路径接受桥接；插件弹窗可主动控制任意普通网页。

## 状态与页面桥接

MV3 后台维护 `chrome.storage.local.petState`，并按需解码当前本地模型的压缩缓冲，没有渲染器或动画定时器。这样严格网页 CSP 禁止 WASM 时，仍可显示真实3D。解码消息只能来自扩展内容脚本，且必须匹配当前村民包内 GLB 的精确缓冲位置、长度和格式；不接受外部模型或任意压缩数据。后台只保留当前一个模型的压缩数据，收回时释放。内容脚本在 `enabled && !document.hidden` 时才动态导入叠层，并且只加载当前角色模型。模型、脚本、解码器均来自扩展目录。

页面允许发送 `window.postMessage({channel:'NAIJIACUN_PET',type:'PING'|'START'|'STOP',requestId,payload:{id,mode,size?}},location.origin)`。回复频道是 `NAIJIACUN_PET_REPLY`，包含原请求 ID、`ok`、`state` 与版本；初始化和存储变更另发 `type:'STATE'` 更新网页状态。

控制只接受同一个顶层 window、同源消息与下列页面路径：`https://163-ai.github.io/naijiacun/`，`http://127.0.0.1:8012/naijiacun/`。角色 ID 和模式必须来自本地目录，不接受任意 URL、代码或模型路径。扩展只申请本地存储权限和匹配普通网站的内容脚本访问。
