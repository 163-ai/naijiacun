奶家村 Windows 透明桌宠 - 使用说明
========================================

【运行】
双击 NaijiacunPet.exe 即可，无需安装。
适用于自带 .NET Framework 4.x 的 Windows 10 / 11。
不需要管理员权限、联网、注册表或开机启动。

【基本操作】
- 按住角色：拖动到屏幕任意位置
- 左键单击：无操作（透明区域可直接穿透点击到下方窗口）
- 右键单击角色：弹出菜单
    * 选择角色：奶龙 / 奶娃 / 宝宝龙 / 小七 / 牛来 / 水豚 / 奶茶 / 奶蛋 / 飞嘟嘟（共九位）
    * 选择尺寸：三档大小
    * 退出：关闭桌宠

【特点】
- 无背景、无边框、窗口置顶，不显示在任务栏
- 透明区域鼠标穿透，不影响下方程序操作
- 尺寸随显示器 DPI 自动缩放，跨显示器拖动会按该屏幕 DPI 重新渲染
- 默认显示奶龙

【说明】
- 本程序使用项目现有的静态全身渲染图，暂不包含网页版的走路、聊天和语音功能。
  想要完整互动体验，请在浏览器打开奶家村网站。
- 本程序未做代码签名，Windows 首次运行可能显示“来源不明”的安全提示，
  确认来源后选择“仍要运行”即可。
- 退出后不会留下后台进程或开机启动项。
