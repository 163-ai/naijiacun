奶家村 · Windows 透明桌宠

1. 把 ZIP 解压到任意文件夹，双击 NaijiacunPet.exe。
2. 奶龙会出现在屏幕右下方。只显示角色，透明区域可以正常点击桌面或其他窗口。
3. 按住角色可拖动位置。右键角色，可切换九位角色、选择小/中/大尺寸，或退出桌宠。
4. 角色保持置顶；退出后不会留下后台进程。删除解压文件夹即可移除。

适用 Windows 10 / 11（使用系统自带 .NET Framework 4.x）。无需安装，不需管理员权限，不联网，不设开机启动。
本便携版本展示项目现有的角色全身渲染图；暂不包含网页里的走路、聊天和语音。
