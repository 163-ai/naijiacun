# 形象图放这里

把每个角色的形象图放进这个目录，然后到 `js/data.js` 里给对应角色填上 `image` 字段即可。

## 用法

1. 图片命名为角色 id + 扩展名，例如：

   ```
   assets/characters/nailong.png
   assets/characters/naiwa.jpg
   assets/characters/baobaolong.webp
   ```

2. 打开 `js/data.js`，找到对应角色，把 `image` 从空字符串改成路径：

   ```js
   {
     id: "nailong",
     name: "奶龙",
     image: "assets/characters/nailong.png",   // ← 改这里
     ...
   }
   ```

3. 保存，刷新页面。卡片和详情弹窗都会用这张图。

`image` 留空时，页面会用 `js/avatars.js` 里的内置 SVG 形象（没有的话退回首字圆牌）。

## 当前九位 3D 渲染形象

`3d/<id>-avatar.png` 是从用户提供、已筛选的模型渲染的图鉴近景头像；`3d/<id>-pet.png` 是同一模型的透明全身图。`js/data.js` 使用 `image` 引用头像，使用可选的 `petImage` 引用桌宠图。桌宠未配置 `petImage` 时回退到 `image`。

原声、聊天人设、角色 ID 保持不变；小草继续使用原有图片。模型来源与处理记录见 [模型来源](../models/SOURCES.md)。

## 建议的图片规格

| 项目 | 建议 |
|---|---|
| 尺寸 | 正方形，至少 400×400（卡片显示 52px，但高清屏需要 2~3 倍） |
| 构图 | 主体居中、留一点边距，页面用 `object-fit: cover` 圆形裁切 |
| 格式 | png（透明底最干净）或 webp（体积小） |
| 单张大小 | 控制在 300KB 以内，否则首次加载会慢 |

## 关于素材来源

这个目录里的内容由你自己决定放什么。需要提醒的是：官方立绘、视频截帧、他人二创作品都受著作权保护，把它们放进公开仓库属于复制与分发，即使不商用、即使只是比赛作品，权利人也有权要求删除。判例已经有过（奶龙形象的玩偶、娃娃机案件都判过侵权）。

自摄、自绘、AI 生成的原创图，或者拿到明确授权的图，放进来没有任何问题。
